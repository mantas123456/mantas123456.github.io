lab-quality-toolkit ↗

labqc: laboratory quality calculations in Python

The calculations an ISO/IEC 17025 lab does every week: GUM uncertainty budgets with Monte Carlo (GUM S1) and correlated inputs, method validation, outlier tests, method comparison, proficiency-test scores, Westgard, CUSUM and EWMA charts, and flue-gas emission correction. energy-forecasting-dashboard ↗

Day-ahead electricity load forecasting for Lithuania

Real hourly load from energy-data-pipeline, scored in a twelve-window rolling backtest against naive baselines and the grid operator's own day-ahead forecast, with a 48-hour horizon so the comparison is fair. XGBoost is 11% better than the naive forecasts but beats the operator's forecast in only 6 of 12 windows, all in months when that forecast ran low. The README shows where the model fails: spring middays, where it has no weather data. Includes a Streamlit dashboard, tests and CI.
