05Portfolio

Projects on GitHub

lab-quality-toolkit ↗

labqc: laboratory quality calculations in Python

The calculations an ISO/IEC 17025 lab runs every week: measurement uncertainty (GUM, Monte Carlo, top-down / Nordtest), regression and calibration, method validation, outlier tests, method comparison, proficiency-test scores, Westgard / CUSUM / EWMA control charts, decision rules and flue-gas emission corrections. Validated against independent reference values (163 cases); on PyPI, with a browser app and a Streamlit app.

Lab Accreditation Handbook

Free practical guide to ISO/IEC 17025: a page per clause, worked examples checked with labqc, 24 editable Word and Excel templates, and browser tools for gap analysis and internal audit planning.

Read the handbook ↗
energy-data-pipeline ↗

Electricity data pipeline

Lithuanian load, load forecasts and prices from the ENTSO-E API into PostgreSQL, with SQL reporting tables, data-quality checks (freshness, gaps, plausible ranges) and a day-ahead forecast; handles revised values, mixed 15-minute and hourly data and daylight-saving days; runs daily on GitHub Actions.

energy-forecasting-dashboard ↗

Day-ahead electricity load forecasting for Lithuania

Real hourly load scored in a twelve-window rolling backtest against naive baselines and the grid operator's own day-ahead forecast. XGBoost is 11% better than the naive forecasts but beats the operator's forecast in only 6 of 12 windows; the README shows where the model fails. Streamlit dashboard, tests and CI.

measurement-uncertainty-handbook ↗

Measurement Uncertainty Handbook

Free guide to method validation and measurement uncertainty: GUM, Nordtest top-down, Monte Carlo and bootstrap, each with a Python notebook on synthetic data, calculated with labqc. CI runs every notebook before the site is published. Early draft: site and data in place, first chapters in progress.
